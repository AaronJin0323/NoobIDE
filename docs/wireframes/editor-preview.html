Notes (en)

  1. Project name and its real location, with “Show in File Explorer” (macOS: “在访达中显示” / “Reveal in Finder”). Always visible so users can find their folder (metric M4, step 8).
  2. Save status is text + icon, never colour alone: “✓ 已保存” Saved · “● 未保存” Unsaved · “⟳ 正在保存…” Saving… · “⚠ 保存失败 — 你的修改还在” Save failed — your edits are kept (click for the cause and “Save elsewhere…”). Autosave and crash recovery have separate indicators; never a generic “backed up” (PLAN §7).
  3. “Preview: on”, “Help”, “More tools” (later: terminal, debugger, Git). Positions stay fixed; nothing moves by inferred skill (PLAN §3).
  4. Collapsible file tree with real filenames, “+File”, “+Folder”, collapse ⟨⟨. Tree rows show the role of the three template files.
  5. File role hint above the editor: “index.html is the page structure: what is on the page (headings, paragraphs, buttons, images).” Dismissible; reappears from Help. Tab “style.css ●” = unsaved changes in that tab (dot + tab tooltip text).
  6. Preview toolbar: “Desktop / Mobile width” (width only — no claim of emulating a phone, PLAN §3), “Refresh”, “Stop”, “Open in browser”. The preview is a separate isolated view, not part of the React page (PLAN §8).
  7. Refresh mode “Auto refresh ▾ / Manual refresh”. Preview state pill: 已停止 stopped · 正在启动 starting · ● 运行中 running · ⟳ 正在刷新 refreshing · ⚠ 无响应 unresponsive (with “Stop and restart”) · ✕ 失败 failed. When a save fails the pill says “预览未更新” preview not updated.
  8. One-time note: “Refreshing reloads the page; form contents and temporary page state are cleared.” “Got it”.
  9. Bottom panel: “Problems (0)” · “Console”. “No problems found.” New problems update the count and badge but never take keyboard focus from the editor (PLAN §3). Panel can be collapsed ⌄.
