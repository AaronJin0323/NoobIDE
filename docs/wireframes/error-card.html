Notes (en)

  1. Top bar gains “⚠ 1 problem” (icon + count + text, dashed outline — not colour alone). The tree marks the file. The editor keeps keyboard focus; nothing pops up over the code (PLAN §3).
  2. Squiggle on the exact span plus a ⚠ glyph in the gutter; hovering shows the same one-line message.
  3. “Problems (1)” · “Console (1)” · filter “Show: all ▾” (static / runtime / resource loading are listed separately, PLAN §9).
  4. Card header: type tag “Runtime error”, location “script.js, line 12:”, message “Cannot find the variable userNmae.” Repeats are deduplicated into “×3” without losing the original details (PLAN §9).
  5. Explanation + concrete check: “Check whether its spelling matches userName (line 9) where it was defined. If the variable has not been defined yet, declare it first.” Matches the PLAN §9 example; the “line 9” link only appears when the language service actually found a similar name.
  6. Actions: “Go to code” (primary; moves cursor to line 12, col 20 and focuses the editor) · “Show original error” · “What does this mean?” (short glossary entry for ReferenceError, from resources/lessons, offline).
  7. Original error, expanded: the browser's exact text and stack, plus source “Preview page (session #4, after the 10:42:07 refresh)”, first and last seen. Attribution to the correct preview session after refreshes (PLAN §9, S16). Logs keep this metadata but never source code.

  1. Uncertain cause (resource 404): “Image images/头像.PNG did not load (404).” Lists “Possible causes:” instead of claiming one — case mismatch (“works on Windows, may not on Mac or a website”) and wrong folder (PLAN §9, §13). Actions add “Show images in file tree”.
  2. After the fix: “✓ Resolved — script.js line 12 did not appear again after refresh.” “Clear resolved problems.” Status returns to Saved, count 0.
  3. Unresponsive preview: “The page has not responded for 5 seconds; there may be an infinite loop (e.g. while (true)). The editor is not affected and your code is saved. Stop the preview, change the code, then start again.” Primary action “Stop and restart preview” destroys/recreates the view (PLAN §8). Threshold set in S14/S16.
