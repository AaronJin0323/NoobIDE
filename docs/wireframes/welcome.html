Notes (en)

  1. “Hi! Let's start with a webpage.” Subtitle: “A webpage is made of HTML, CSS and JavaScript files. They are kept in an ordinary folder on your computer.” Uses real terms from day one (PLAN §1 principles).
  2. Primary action “Create my first webpage” — the only filled button, first in focus order, Enter activates it. Target: page visible in ≤ 3 min (metric M1).
  3. “Open folder…” opens any existing folder; external projects open read-first, scripts run only after “Start preview” (PLAN §8).
  4. “See what this app can do (2-minute tour)” — optional, skippable walkthrough (S23). Never auto-starts over the user's work.
  5. “Recent projects” with the full real path under each name (paths with Chinese characters and spaces). A missing folder is marked with ⚠ and text “folder not found”, not colour alone, and offers “Remove from list” — never deletes anything on disk.

Notes (en)

  1. “Choose a template”: Personal introduction (default) · Product showcase · Button counter — exactly three in v1 (PLAN §2). Thumbnails are bundled images, works offline.
  2. “Name your webpage” — becomes the folder name. Spaces and Chinese characters allowed; names illegal on Windows or macOS are explained inline (PLAN §7).
  3. “Where to save it” with “Change…” (native folder picker). Default is a visible folder in Documents, not app data. The line below shows the exact folder that will be created and its files, so the user knows where the project lives (metric M4).
  4. Existing folder: “A folder with this name already exists. Please choose another name — we never overwrite existing files.” Create button stays disabled. Buttons: “Cancel” · “Create and open”. After creation the editor+preview screen opens with the template already running in preview (built-in templates are trusted, PLAN §8).
