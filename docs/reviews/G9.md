## Verdict

**Conditional pass on macOS arm64; not passed on Windows x64.** The AI assistant may ship to Mac testers only as a
**preview** (the install docs say so) once condition 1 is met; it is not ready for Windows.

- macOS arm64: criteria 2–4 pass at `af7b57a` with automated evidence (AI e2e 24/24, full e2e suite, 265 AI
  unit/integration tests, security review with every finding fixed and re-checked). Criterion 1 passes against the
  fake provider and the real SDK clients with a mocked transport; it has **never run against the real Anthropic or
  OpenAI service** (no keys available to agents).
- Windows x64: **no evidence at all for M9.** None of the AI commits (S31–S36) has been pushed, so CI has never run
  them. The latest CI run on main (38695944850, `e9ddf49`, before any AI code) failed Windows e2e on three non-AI
  tests.

**Conditions to turn this into a pass** (each one is checkable):

1. The owner runs `npm run test:ai-live` with an Anthropic key and an OpenAI key and checks the four printed outputs
   per provider (`harness/MANUAL-CHECKS.md#S36.1`). Closes S36.1 and the "real key" half of criterion 1.
2. The AI work is pushed and a CI run on main is green on **both** jobs through e2e (the five `ai-*.spec.ts` files
   run on `windows-latest`), with the three current Windows e2e failures fixed or explained (history storage S21.4,
   console flood S05.3/S05.7, recovery S12.2).
3. On Windows, the key is stored through `safeStorage` (DPAPI) in a real run: AI Settings → save a key → restart →
   "Key saved" is shown and Test connection succeeds (add to the S36.1 live check on the Windows dev machine).

S36.1 therefore stays `needs_manual_check` and S36.2 is `done` only for its own criterion (docs and this review);
the milestone is not closed.

## Risks

- **Real-provider behaviour is unproven** (condition 1): model ids, streaming shapes, refusals, prompt caching and
  OpenAI default selection have only been tested against mocked transports. The live test covers one request per
  purpose, not long agent turns.
- **Windows is untested** for everything in M9, including `safeStorage` on DPAPI and paths with Chinese characters
  in agent tools (covered on macOS by `ai-agent.test.ts`).
- **Cost:** agent turns at default budgets (30 steps, 1.5 M tokens) can cost a few dollars on Opus-class models; the
  UI shows usage per answer but has no spend cap. The install docs point users to the provider's monthly limit.
- **Prompt injection** is mitigated (data framing, proposals need approval, no shell, no network tools) but not
  eliminated: a malicious project file can still steer the _content_ of proposals the user then accepts.
- **Accepted info-level residuals** from the re-check: stripping a header named in `*_CUSTOM_HEADERS` that the SDK also
  needs fails safe (AI stops working); an agent turn ended by the 2-hour backstop is reported as cancelled, not as a
  timeout.
- PLAN §4/§7 still exclude AI chat until the owner edits them (decision 0025 "Consequences").
