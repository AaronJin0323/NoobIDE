## Measured hours

**Method.** The project has no time log, so hours are derived from git: every commit's author timestamp on all
refs (`git log --all --format=%at`, 221 commits, identical to main because every branch has been merged), sorted and
split into activity spans wherever two consecutive commits are more than 60 minutes apart; each span counts from its
first to its last commit plus 15 minutes of lead-in. The same with a 30-minute gap gives 9.3 h instead of 9.6 h, so
the result is not sensitive to the threshold. The script is a 30-line Node program over that output (not committed;
the method above reproduces it).

Limits of the method: (a) it measures **wall-clock time during which at least one agent was committing**, not
agent-hours — waves ran 4–7 agents in parallel (PROGRESS sessions 4, 9, 10), so agent effort is several times larger;
(b) Session 0 and most of Session 1 happened before `git init` (first commit 2026-10-14 13:51 +11:00) and are not
counted; (c) work that was lost is not counted — the Windows-only wave-2 branches (S05.7, S14, S15, S16.2–S16.4, S17,
S22.4/S22.5, S06) were never pushed and were rebuilt on the Mac in session 10; (d) owner time (reviews, merges,
machine setup, the CI repository) is not in git at all.

## Risks

1. **Windows evidence lags the code.** The first green Windows `verify` in CI is from the reviewed commit; Windows e2e
   has never passed in CI and no Windows installer exists. Everything built on the Mac in sessions 9–10 is unproven on
   Windows. Every gate after G1 inherits this until CI is green on both platforms on every push.
2. **Isolation under load on Windows.** The worker-flood stall (356 ms on the CI runner vs 15–21 ms on Apple Silicon)
   is the one M1 isolation measurement over budget. PLAN §8 treats isolation failures as stop-the-line; it needs a
   run on the Windows dev machine to tell runner noise from a real cost.
3. **Lost work from unpushed branches** (session 4 → 10). Mitigated now that the repository and CI exist; the rule
   should be "push every branch at the end of a wave".
4. **Unsigned builds.** The macOS ad-hoc signature is invalid after packaging (G3.md); Gatekeeper refuses the app
   from a download unless the quarantine mark is removed by hand.
5. **Velocity numbers are not effort numbers.** The 9.6 h figure is wall-clock with parallel agents and excludes
   pre-git work, lost work and owner time; it should not be read as "the MVP took ten hours".
